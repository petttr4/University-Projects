
# jvmLExp — Μεταγλωττιστής Προθεματικών Αριθμητικών Εκφράσεων σε JVM Bytecode

Ατομική εργασία στο μάθημα **Γλώσσες Προγραμματισμού και Μεταγλωττιστές**
Τμήμα Εφαρμοσμένης Πληροφορικής, Πανεπιστήμιο Μακεδονίας
Τσιμπίνη Πετρούλα (ics23085) — Ιούνιος 2026

## Περιγραφή

Μεταγλωττιστής για μια γλώσσα αριθμητικών εκφράσεων σε **προθεματική
μορφή**, που παράγει **JVM assembly (Jasmin)**. Υλοποιήθηκε με **Flex**
(λεκτικός αναλυτής, `jvmLExp.l`) και **Bison** (συντακτικός/σημασιολογικός
αναλυτής, `jvmLExp.y`) πάνω σε δοσμένο σκελετό υποστήριξης (πίνακας
συμβόλων, διαχείριση ενδιάμεσου κώδικα κ.λπ.).

**Χαρακτηριστικά:** δηλώσεις `int`/`float`, ανάθεση με αυτόματη μετατροπή
τύπου, τελεστές `+ - * /`, `++` (pre/post), έκφραση υπό συνθήκη
`(relop lhs rhs ? true : false)` με backpatching, `print`, και ανίχνευση/
ανάκαμψη σημασιολογικών σφαλμάτων (διπλή δήλωση, μη δηλωμένη μεταβλητή,
type mismatch).

## Απαιτήσεις

`gcc`, `flex`, `bison`, [`jasmin`](http://jasmin.sourceforge.net/), Java

## Build & Εκτέλεση

```bash
make                       # μεταγλώττιση -> εκτελέσιμο jvmLExp
./jvmLExp <input> <out.j>  # απευθείας χρήση

cd Examples
./compile_and_run simple1  # μεταγλωττίζει, τρέχει jasmin, εκτελεί σε Java
```

`make clean` καθαρίζει τα build artifacts, `make cleanFiles` τα `.j`/`.class`
στο `Examples/`.

## Παραδείγματα

Στο `Examples/` υπάρχουν εννέα παραδείγματα (`simple1`–`simple9`) και ένα
παράδειγμα σφαλμάτων (`simple_error`). Αναλυτικός σχολιασμός καθενός
(είσοδος, παραγόμενος κώδικας, αντιστοίχιση με τη γραμματική) βρίσκεται στην
αναφορά [`report2_ics23085.pdf`](./report2_ics23085.pdf).
