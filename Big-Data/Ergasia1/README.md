# Big Data

Ατομική εργασία στο πλαίσιο του μαθήματος Big Data, με αντικείμενο την ανάλυση δεδομένων πτήσεων (flights_2000.csv) χρησιμοποιώντας Apache Spark.

## Περιγραφή

Η εργασία συγκρίνει δύο διαφορετικές προσεγγίσεις επεξεργασίας δεδομένων στο Spark — το **RDD API** και το **DataFrame API** — υπολογίζοντας τη μέση καθυστέρηση πτήσεων και οπτικοποιώντας τα αποτελέσματα.

### Θέματα που καλύπτονται
1. **Spark RDD API** – Υπολογισμός μέσης καθυστέρησης ανά αεροδρόμιο αναχώρησης (top-10) με χρήση `combineByKey`
2. **Spark DataFrame API** – Υπολογισμός μέσης καθυστέρησης ανά διαδρομή (top-10) με χρήση `groupBy`/`agg`
3. **Σύγκριση RDD vs DataFrame API** – Ανάλυση διαφορών σε χρόνο εκτέλεσης, ευκολία ανάπτυξης και βελτιστοποίηση (Catalyst Optimizer)
4–5. **Οπτικοποίηση** – Ραβδογράμματα και heatmap για ανάλυση καθυστερήσεων ανά διαδρομή, ώρα ημέρας και αεροπορική εταιρεία
