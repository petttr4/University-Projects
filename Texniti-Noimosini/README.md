# Τεχνητή Νοημοσύνη - Εργασία 2

Ατομική εργασία στο πλαίσιο του μαθήματος Τεχνητή Νοημοσύνη.

## Περιγραφή
Υλοποίηση και δοκιμή αλγορίθμου αναζήτησης (Hill Climbing) με διαφορετικές παραμέτρους βάθους (depth).

## Περιεχόμενα
- `TN2_ics23085.pdf` - Αναφορά της εργασίας
- `run_*.bat` - Scripts εκτέλεσης του αλγορίθμου με διαφορετικές παραμέτρους
- `test*.txt` - Αρχεία δοκιμών (test cases)
- `results.txt` - Αποτελέσματα εκτέλεσης
